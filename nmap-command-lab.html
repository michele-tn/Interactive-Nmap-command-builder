Freshness you can verify

The official GitHub mirror is synchronized from SVN hourly. A verified catalog means the sources were checked at the displayed time; it does not guarantee that an offline copy is current. Nmap mirror policy ↗

  1. Automatic verification runs when the catalog is over one hour old, while the page stays open, and when you return to the tab.
  2. The server uses conditional requests. Direct browser updates use the CORS-enabled official mirror. Both enforce timeouts, size limits and schema checks.
  3. A new catalog becomes active only when every source passes validation.
  4. A failed check keeps the previous catalog and displays a warning. Successful updates are saved in this browser when storage is available.
The SVN channel includes features in development. Check nmap --version: your installation may not support every option. Local checks cover major conflicts, not every possible combination.
